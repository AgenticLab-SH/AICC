공식 목록 확인 중

무료 한도는 모델별 별도 금액이 아니라 두 원시 token 풀에서 공유됩니다. 각 행은 그 모델이 실제로 소비한 풀 비율과 표준요금 환산액을 표시합니다. 무료 등록 상태 · 공식 서비스 티어 사용량 · 비용 확인

무료 할당량은 모델별이 아니라 두 모델 그룹에서 공유됩니다. AICC는 전역 풀의 95%에서 정지하고, 각 Git 프로젝트는 기본적으로 풀별 10%까지 사용합니다. 공식 무료 대상 목록과 실제 계정 접근 가능 여부는 구분해 표시하며, “연결 확인”은 고정된 비민감 문장으로 최소 API 요청을 보냅니다. 프로젝트는 키를 받지 않고 AICC CLI를 subprocess로 호출하며, 정적 프런트엔드에는 API 키를 넣지 않습니다.
