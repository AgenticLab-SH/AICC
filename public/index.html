→ 두 개의 전용 Tunnel AICC 소유 구현AICC Workspace MCP

작업공간 registry, lease, 경로 검증, seatbelt, 13개 도구와 대시보드는 AICC가 직접 구현·유지합니다.

→ 외부 ChatGPT 로컬 작업 아이디어만 참고 · 자동 추적 안 함Waishnav/devspace

범용 workspace 제어 방향을 비교했습니다. 코드·패키지·프로세스는 채택하지 않았고 필요한 경계는 AICC가 다시 구현했습니다.

→ 런타임 의존성 없음 표현 규격 참고 · 런타임 의존성 없음Obsidian JSON Canvas

카드·그룹·연결선 방식과 공개 .canvas 규격을 구조 지도에 활용했습니다. Obsidian이나 커뮤니티 플러그인 설치는 필요 없습니다.

printf '질문' | aicc openai ask --model gpt-5.4-mini --max-output 512

무료 할당량은 모델별이 아니라 두 모델 그룹에서 공유됩니다. 그래서 공식 “모델별 무료 퍼센트”는 없습니다. AICC는 그룹의 실제 토큰 비율과 각 모델의 입력·캐시·출력 토큰, 공식 표준요금 환산액을 함께 표시합니다. 웹 대시보드 수치는 AICC guard를 거친 요청에 즉시 반영됩니다.
