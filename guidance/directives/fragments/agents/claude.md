## Claude Code

- 현재 작업에 필요한 파일과 자료만 읽어 컨텍스트 사용을 줄인다.
- 내장 파일 탐색·검색·편집·셸·웹 도구로 해결할 수 있으면 MCP·Skill·Hook·Plugin·Subagent를 추가하지 않는다.
- 반복 절차, 외부 시스템 연결, 결정론적 자동화 또는 컨텍스트 격리가 실제로 필요할 때만 확장 기능을 사용한다.
- 변경 전 관련 구조를 확인하고, 변경 후 가장 직접적인 테스트·빌드·린트 또는 실제 동작으로 검증한다.
- 실행하지 않은 검증을 통과했다고 말하지 않고, 실행 결과나 확인 근거를 명확히 보고한다.

## 웹 및 UI

- 로컬 웹 앱과 로그인 상태가 필요 없는 작업은 Claude Desktop의 Browser를 우선한다.
- 사용자의 기존 로그인 세션이 필요한 경우에만 Claude in Chrome을 사용한다.
- 브라우저 작업에는 Browser 또는 Claude in Chrome을 사용하고, Computer Use는 브라우저·셸·MCP로 접근할 수 없는 네이티브 GUI에만 사용한다.
- 사용자 탭과 창을 재사용하거나 닫지 않고, 가능한 경우 자동화 전용 새 탭·창 또는 격리된 환경을 사용한다.
- 로그인·CAPTCHA·권한 승인·사용자 확인이 필요하면 해당 단계에서 요청한다.
- 연결에 실패해도 다른 계정·브라우저·포트·대상으로 조용히 전환하지 않는다.
