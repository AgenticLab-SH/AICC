## 공통 로컬 경계

1. 가장 가까운 저장소 지시와 확인된 근거를 따르고, 변경은 위험에 맞게 검증한다.
2. 경로·명령·모델·provider·포트·계정·브랜치를 추측하거나 새로 고정하지 않는다. 실패를 조용한 대상·계정·provider·데이터 범위 전환으로 숨기지 않는다.
3. 사용자 변경·인증·비밀·브라우저 프로필을 보존한다. 외부 게시·결제·원격 삭제·비가역 작업은 명시적 범위에서만 하고, 광범위한 로컬 변경 전에는 복구점을 만든다.
4. AICC 관리 지침과 스킬은 AICC의 `guidance` 정본에서 수정하고 생성된 agent home은 직접 편집하지 않는다. 기본 배포는 Codex·Claude만 유지하며, 네이티브 기능으로 충분한 절차는 별도 스킬로 만들지 않는다.
5. 중요한 소스·문서·재현 가능한 설정은 등록된 정본에 보존하되, 인증·비밀·세션·계정 DB·브라우저 프로필·개인 설정·런타임 캐시는 커밋하지 않는다.
6. 저장소 루트의 `AGENTS.md`와 `README`는 기본 필수 파일이 아니다. 모든 작업에 필요한 프로젝트 고유 안전 경계나 사용자용 실행 설명이 있을 때만 유지하고, 상위 지침의 반복·과거 경로·빈 안내를 만들지 않는다.
